# Architecture Overview

`template-go` is a production-ready HTTP REST service template written in Go using Chi router, pgx/v5 connection pooling, and sqlc.

## Physical Directory Structure
- `cmd/server/main.go`: Application entrypoint, server lifecycle, and graceful shutdown.
- `internal/config/`: Strongly typed environment configuration (`config.go`).
- `internal/handler/`: HTTP handlers and request/response DTOs (`health.go`, `notes.go`).
- `internal/db/`: Type-safe SQL models and query functions generated by sqlc.
- `sql/`: Canonical relational database DDL (`schema.sql`) and queries (`queries.sql`).

## Tenant Isolation & Invariants
- Multi-Tenant Invariant: Every read and write query on `notes` strictly filters by `owner_id`.
- Tenant extraction: Request header `x-user-id` extracts the tenant `owner_id` at the HTTP boundary.
- Zero Global State: Handlers receive database queries explicitly via dependencies injection (`NewNotesHandler(queries)`).
